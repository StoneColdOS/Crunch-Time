# Crunch Time

A Dave the Diver style diner game set in a foggy 90s fast-food joint at 1 a.m. The cook makes the food. You run it to the booths before anyone calls corporate.

**Play:** https://stonecoldos.github.io/crunch-time/

## Controls

| Action | Controller (AYN Thor) | Keyboard |
| --- | --- | --- |
| Walk | D-pad / left stick left-right | Left / Right or A / D |
| Choose held item | L / R or D-pad up-down | Q / E or Up / Down |
| Take, pour, serve | A | Z or Space |
| Toss held item | B | X |
| Start | Start | Enter |

Touch buttons show up on phones.

## Repo layout

- `prototypes/` holds earlier builds, kept for reference.
