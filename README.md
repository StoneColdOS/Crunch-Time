# Crunch Time

A 90s fast-food rush game inspired by the sushi bar in Dave the Diver. Walk the kitchen, grab the food, pack the bags, and serve everyone before they call corporate.

**Play:** https://stonecoldos.github.io/crunch-time/

## Controls

| Action | Controller (AYN Thor) | Keyboard |
| --- | --- | --- |
| Walk | D-pad / left stick left-right | Left / Right or A / D |
| Switch held item | D-pad up-down | Up / Down or W / S |
| Grab, start machine, bag item | A | Z or Space |
| Toss held item | B | X |
| Start | Start | Enter |

Touch buttons show up on phones.

## Repo layout

- `index.html` is the current playable build.
- `prototypes/` holds earlier builds, kept for reference.
- `DESIGN.md` is the design doc and the parking lot for new ideas.
